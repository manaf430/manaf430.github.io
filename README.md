# manaf430.github.io

Personal portfolio website for GitHub Pages.

## Deployment

This repository is a user-site repo (`manaf430.github.io`), so pushing to the default branch automatically deploys the site at:

- https://manaf430.github.io/

## Customize

Update content in `index.html`:

- Hero text (name/intro)
- Project cards and live links
- Skills and contact section
